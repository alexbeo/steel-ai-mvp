Konsequenz Einkaufsentscheidungen müssen vier Dimensionen gleichzeitig halten — Zusammensetzung × Kosten × Volatilitätsrisiko × Spezifikation — und das Know-how der Organisation über Personalwechsel hinweg bewahren. Heute geschieht das sequenziell, in getrennten Tools, mit einem Lag von Tagen.

Plattform

Die Plattform auf einen Blick.

Vier Schichten. End-to-End in 30–90 Sekunden auf Standard-Hardware, ohne GPU-Cluster. Klicken Sie auf eine Schicht, um die technischen Details zu sehen.

Input
Zielspezifikation + Rohstoffpreis-Snapshot. Beispiel API 5L X65 · EUR/kg live oder YAML · 11 Ferrolegierungen + Schrott.
Seed-Benchmark 23.04.2026 · austauschbar durch Live-API oder manuelle Eingabe. Jede Optimierung wird mit einem Preis-Snapshot im Decision Log festgeschrieben. Physikalische Grenzen (Chemiebereiche der Stahlklasse) vorab validiert.
Engine
Forward-ML · Inverse Design · Physik-Validator · Critic-Schicht. XGBoost mit Quantile Regression (90 %-CI) → NSGA-II Multi-Objective → CEV / Pcm / CEN / Schweißbarkeit / OOD → Pattern Library (20+ Anti-Patterns) + Claude Sonnet LLM-Review.
XGBoost Objective: L(φ) = Σ l(ŷᵢ, yᵢ) + Σ Ω(fₖ) · Ω(f) = γT + ½λ‖w‖². NSGA-II: Non-dominated Sort · Crowding Distance · elitist selection · population 80, generations 60. Conformal Prediction für kalibrierte 90 %-CI mit mathematischer Abdeckungsgarantie.
Output
Top-5 Pareto-Kandidaten. Chemie · Prozessparameter · σt ± CI · EUR/t-Breakdown je Ferrolegierung · OOD-Flag · nächste EN / API-Güte.
Jeder Kandidat als JSON exportierbar. SHAP-Attribution auf Feature-Ebene erklärt, warum dieses Rezept gewählt wurde. ONNX-Export der Modellgewichte für Langzeitarchivierung möglich. HTML-Report pro Run.
Audit
Decision Log · SQLite · EU-resident. Jede Anfrage mit Snapshot: Preise, Constraints, Top-5-Alternativen, Begründung, Autor. Nach Jahren rekonstruierbar. Compliance-ready.
Standard-SQLite-Datei · exportierbar, migrationsfähig. Schema: decisions(id, timestamp, phase, decision, reasoning, alternatives_considered, context, author, tags). Read-API für BI-Anbindung.

Al-Desoxidationsgleichgewicht — drei Modelle, eine Wahrheit.

Reaktion im Pfannenofen bei T ≈ 1873 K (1600 °C). Alle drei Formulierungen1,2,3 sind in der Plattform parallel implementiert. Die Streuung zwischen den Modellen ist die ehrliche Unsicherheitsangabe — kein Single-Number-Pseudowert.

Gleichgewichtsreaktion
2 [Al] + 3 [O] ⇌ Al2O3(s)
log ( [%Al]2 · [%O]3 ) = −64 000 / T + 20,54
Fruehan, R. J. (Carnegie Mellon University) — The Making, Shaping and Treating of Steel, 11. Auflage, AISE Steel Foundation, 1998. ISBN 978-0-930767-02-0
Genauigkeitsklasse: ±40 ppm bei [Al] < 0,05 %.
Klassische Referenz, konservative Vorhersage bei niedrigen Al-Gehalten. Dominanter Einfluss: Temperaturabhängigkeit der Gibbs-Energie.
Gleichgewicht · mit Wechselwirkungsparametern
2 [Al] + 3 [O] ⇌ Al2O3(s)
log ( [%Al]2 · [%O]3 ) = −62 780 / T + 20,17 + Σ eij
Sigworth, G. K.; Elliott, J. F. (MIT) — Metal Science, Vol. 8, 1974, S. 298–310. DOI 10.1179/msc.1974.8.1.298
Genauigkeitsklasse: ±30 ppm bei [Al] = 0,01–0,05 %.
Berücksichtigt explizit die Wechselwirkungsparameter eAlO und eOAl. Besserer Fit im kritischen mittleren Al-Bereich.
Gleichgewicht · moderner Datensatz
2 [Al] + 3 [O] ⇌ Al2O3(s)
log ( [%Al]2 · [%O]3 ) = −66 300 / T + 20,91
Hayashi, M.; Yamamoto, H. — ISIJ International, Vol. 53, No. 10, 2013, S. 1735–1742. DOI 10.2355/isijinternational.53.1735
Genauigkeitsklasse: ±20 ppm bei [Al] > 0,05 %.
Neueste Messdaten aus japanischer Laborreihe. Engster Streubereich bei hohen Al-Gehalten — empfohlen für Al-reiche Stähle.
fig. Al–O Gleichgewicht · T = 1873 K (1600 °C)
Konsequenz. Bei [Al] = 0,03 % schwanken die drei Modelle um ±40 ppm im [O]-Gleichgewicht. Diese Streuung ist keine Schwäche der Plattform — sie ist die reale Unsicherheit der Physik bei industriellen Bedingungen. Ein einziges Modell würde diese Unsicherheit verschleiern.
