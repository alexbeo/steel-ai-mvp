# Discussions Archive

Постоянное хранилище ключевых обсуждений по продуктовому направлению, архитектурным решениям и стратегии развития steel-ai-mvp.

**Цель:** удерживать контекст между сессиями. ML-предсказания и git-история фиксируют *что было сделано* и *почему конкретный коммит*; обсуждения здесь фиксируют *почему мы выбрали этот путь развития* и *какие альтернативы рассматривались*.

**Не место для:**
- Отчётов о выполненных шагах (это идёт в `docs/path*_*.md`)
- Технических спецификаций (это идёт в `docs/` как design docs)
- Daily-tasks (это в TaskCreate)

**Формат файла:**
- Имя: `YYYY-MM-DD_kebab-case-topic.md`
- Frontmatter: title, date, status (open / decided / superseded), participants
- Тело: структурировано как «контекст → варианты → trade-offs → решение → next steps»
